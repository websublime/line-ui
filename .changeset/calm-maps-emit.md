`@websublime/line-genui/catalog` now emits the `line` A2UI catalog (`lineCatalogDocument`, `inlineCatalog`, `lineCapabilities`) and exports the `basic` implementation map (`basicImplementations`), the built document ships as `@websublime/line-genui/catalog.json`, and `@websublime/line-icons/a2ui` (Preview) adds `a2uiIconMap(set, { library })`, which maps the 59 A2UI icon names to Lucide or Phosphor for the surface `iconMap`.
