## Understanding
- Outcome: the Storybook toolbar has two independent menus, one for `data-accent` and one for `data-gray` on the
  preview `<html>`, so authors can set any of the 31 × 6 pairs and see the PRD §9.5 defaults and auto-pairing.
- Stated (Miguel): two native `globalTypes` menus; `@storybook/addon-themes` goes.
- Assumed (orchestrator defaults, Miguel may correct):
  - The menus list `ACCENT_HUES` and `GRAY_HUES` from `@websublime/line-schemas`, with no hue written by hand,
    so the `00-C16` hue rename reaches the toolbar without an edit.
  - Each menu's first entry removes its attribute (accent "default", gray "auto"), and those entries are the
    initial globals. The preview then starts on the PRD defaults (indigo accent, auto-paired gray).
  - A decorator in `preview.ts` sets or removes `data-accent` / `data-gray` on `document.documentElement`.
  - `@storybook/addon-themes` leaves `main.ts` `addons`, the root `devDependencies` and `bun.lock`.
  - The branch carries an empty changeset; no published package changes.
