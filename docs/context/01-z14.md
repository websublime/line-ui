## Decisions (Miguel, 2026-11-26)
- SD76: keep the widening duty and `onlyUpdatePeerDependentsWhenOutOfRange`; the AM rewords the reason, which under
  Changesets 3 is to keep the union range that admits the previous phase's peers, no longer to prevent a major.
- `changesets/action` moves to v2 with `push-with-git-cli: true`, keeping today's checkout-credential model (AM-038).
- Snapshot workflows with nothing pending: `changeset version --snapshot` fails, as upstream intends; each workflow
  documents it.
- Markdown: exclude `**/*.md` from Biome and set `format: false` in `.changeset/config.json`.
- `@changesets/get-github-info`: remove the unused direct devDependency.
- `NPM_TOKEN` in `release.yml`: dropped. `changesets/action` v2 writes no `.npmrc`, so the line was inert;
  `release.yml` publishes through OIDC only, and a bootstrap token reaches only the `snapshot-deploy.yml` fallback
  step (option (a) over a new `~/.npmrc` step or an inert line).
- SD76 guard (Miguel, 2026-11-26, option (a) over a separate row or none): under Changesets 3 a missed widening gives
  `line-genui` a `patch` and rewrites its peer range to `workspace:^0.3.0`, which the Version PR version check no
  longer catches. Z14 adds a CI step (a `scripts/` check run in `checks.yml`) that fails when the `changeset status`
  plan takes `line-components` or `line-icons` to a version outside `line-genui`'s peer ranges. A Phase 1 spec AM
