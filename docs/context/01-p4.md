## Deviations (approved by Miguel on 2026-11-18)
- **Step 3 order.** Phase 00 spec §7.2 step (3) (`docs/specs/00-spec-design-system.md:2515`) and the AM-038 order

- **Actor.** Spec §6.P.4 names infra-supervisor as the owner, but the main session (orchestrator) ran the two
  `snapshot-deploy.yml` dispatches (steps 2 and 5) and deleted the environment secret (step 3, GitHub half).
  Miguel approved this with the initial plan. The main session edited no file that way, and the
  infra-supervisor role wrote this file.

## Decisions
- **Publisher permissions.** Miguel decided to keep `npm publish`, `npm stage publish` and `npm dist-tag` on the
  `snapshot-deploy.yml` publisher. The spec asks only that "npm publish" be ticked and forbids nothing else.
  The security reviewer recommended dropping the extras, because `npm dist-tag` would let a compromised run
  move `latest` or `canary` back to an old version, `npm stage publish` is unused, and the publisher runs only
  `npm publish … --tag <opts.tag>` (`scripts/publish.mjs:169`), with `canary` set by `snapshot:publish`
  (`package.json:31`).
