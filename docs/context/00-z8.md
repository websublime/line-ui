## Class and ceremony
- Class: `change`. The spec neither requires nor forbids the work. It deletes repository settings (Pages,
  environments, a secret) and changes what npm shows for a published package. `task` does not fit because
  the row has no spec section.
- Ceremony: understand → decide → implement → verify → track. The main session (row owner) runs implement
  as `gh`, `git push`, and `npm` commands. The branch changes only the ledger, this file, and an empty
  changeset.
- Verify: `bun run lint`, the `reviewer` checklist, and `security-reviewer`, because a secret, environments,
  and registry state change.

## Understanding
- Outcome: no vitamin-era state remains on GitHub or the registries apart from git history.
- Stated (row): 21 releases and 21 tags `@websublime/vitamin-*`; GitHub Packages `vitamin-ui`,
  `vitamin-core`, `vitamin-theme`; environments `ci` and `github-pages`; the GitHub Pages site; the unused
  repo secret `GH_TOKEN`; deprecate `@websublime/vitamin-ui` on npmjs.
- Assumed:
  - Git history stays. Deleting a tag removes only its name.
  - Release notes need no backup, because `packages/{ui,theme,core}/CHANGELOG.md` at the tagged commits
    carry them.
  - GitHub Pages stays off until a Storybook deploy needs it.

## Acceptance criteria
1. `gh release list` shows no `@websublime/vitamin-*` release; the 8 `line-*@0.1.0` releases remain.
2. `git ls-remote --tags origin` shows no `@websublime/vitamin-*` tag; the 8 `line-*@0.1.0` tags remain.
3. The org's npm package list on GitHub Packages shows no `vitamin-ui`, `vitamin-core`, `vitamin-theme`.
4. The repository environment list shows only `npm`.
5. `GET repos/websublime/line-ui/pages` returns 404, and the Pages URL no longer serves the vitamin
   Storybook.
6. `gh secret list` shows no `GH_TOKEN`.
7. `npm view @websublime/vitamin-ui deprecated` prints the deprecation message.
8. The branch carries an empty changeset, and `bun run lint` passes.

## Affected packages and apps

## Public surface touched
- `npm install @websublime/vitamin-ui` prints a deprecation warning. `npm deprecate <pkg> ""` reverts it.
- https://websublime.github.io/line-ui/ stops serving.
- Installs of `@websublime/vitamin-*` from `npm.pkg.github.com` fail. GitHub restores a deleted package
  within 30 days, and it refuses to delete a public package version with more than 5,000 downloads.
- Deleted releases, tags, environments, Pages config, and the secret do not come back. Each except the
  release text is recreated in minutes.
