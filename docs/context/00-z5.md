## Understanding
- Outcome: every published `@websublime/line-*` tarball declares its license and ships the license text, and
  the repository's license metadata is consistent.
- Found: root `package.json` declares `"license": "ISC"`, while the root `LICENSE` file is the MIT text with
  `Copyright (c) 2020 Vitamin UI` (inherited from the earlier project). None of the 8 packages declares
  `license` or carries a `LICENSE` file, so npm warns at publish and consumers see no license.

## Decisions (Miguel, 2026-10-02)
- **MIT, holder updated.** The root `LICENSE` keeps the MIT text with the line
  `Copyright (c) 2026 Miguel Ramos / websublime`. The root and the 8 packages declare `"license": "MIT"`.
  Each package carries a copy of the root `LICENSE`, so its tarball ships the text (Bun always adds
  `LICENSE*`). Rejected: ISC (would replace the existing MIT text); MIT with the file unchanged (stale
  holder).

## Acceptance criteria
1. Root `LICENSE` is MIT with the updated holder line; `packages/*/LICENSE` are byte-identical copies.
2. Root and 8 package manifests declare `"license": "MIT"`.
3. `bun run scripts/verify-pack.mjs` passes and each of the 8 tarballs contains `LICENSE` and a manifest
   with `"license": "MIT"`.
4. Verify record: `bun run lint`, `bun run build`, guard, `bun run release --dry-run`; changeset `patch` for
   the 8 packages.
