## Understanding
- Outcome: `@websublime/line-components/grid` registers `<line-grid>`, a Static CSS Grid layout container whose
  column count responds to its own width, with `agentExposed: true` and a `Grid` descriptor in the `line` catalog.
- Stated:
  - PRD §4.1 (`docs/PRD.md:264`): Static, "CSS Grid layout wrapper with responsive column control".
  - Phase 1 spec row C17: Static, tag `line-grid` at `./grid`, role settled by the component spec from R8 §2.2,
    not form-associated, `agentExposed: true`, htmx `n/a` expected.
  - R8 (`docs/research/01-research-accessibility.md:81`): no role; the ARIA `grid` role and APG Grid describe an
    interactive widget, which a CSS grid wrapper is not.
  - Miguel's decisions, 2026-11-16, each the recommended option of `0019-grid.md`:
    - F1 (b): `columns` caps the count (`1`–`12`, default 12) and `min-column-width` (`none | xxs | xs | sm | md`)
      sets the narrowest column, in one template rule with no breakpoint.
    - F2 (a): `auto-fill`, so items in a short row keep their column width.
    - F3 (b): one `gap` attribute on Stack's `0`–`5` scale, plus the `--line-grid-gap`, `--line-grid-row-gap` and
      `--line-grid-column-gap` tokens.
    - F4 (a): `align` (`align-items`) and `justify-items`, each `start | center | end | stretch`.
    - F5 (a): Grid offers nothing for spanning; the consumer styles the child.
    - F6 (a): the five layout props and `children` reach agents, in the `line` catalog only.
    - F7 (a): `columns` is a string enum `'1'`–`'12'`.
    - F8 (a): `hostNaming: never`; the Grid tool carries no accessibility parameters (Phase 1 spec AM-101).
    - F9 (a): no `rows`, `flow`, `areas` or `inline` prop.
  - Miguel, 2026-11-16: the defaults D1–D20 stand as drafted.
- Observed (spec-draft probes P1–P11, Playwright 1.64.0 on chromium 156, firefox 157 and webkit 27.2, happy-dom
  20.14.6, htmx 2.0.11 and 4.0.0, axe 4.14.0; recorded in `0019-grid.md` Probes):
  - A role-less grid adds no node to the Chromium accessibility tree; a labelled one is a named `generic`, and axe
    is silent about it (P1).
  - A host cannot answer a container query about itself, and an inner wrapper collapses inside flex rows and breaks
    host list roles, so the single template rule carries the responsiveness (P2, P3).
  - A unitless `0` in a gap or size token collapses the template to one column; `0px` does not (P2).
  - No A2UI basic type in v0.9 or v0.9.1 maps to a grid (P9).
- Assumed: none beyond defaults D1–D20.
