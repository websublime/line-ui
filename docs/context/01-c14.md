## Understanding
- Outcome: `@websublime/line-components/kbd` registers `<line-kbd>`, a Static component that draws a keyboard
  shortcut for the user's device, `⌘K` on Apple devices and `Ctrl+K` elsewhere, from a `keys` attribute, with
  English words for assistive technology that the consumer can replace. It carries `agentExposed: true`, with one
  agent prop, `keys`.
- Stated:
  - PRD §4.1 (`docs/PRD.md:260`): Static, "Keyboard shortcut display with OS-aware rendering (Cmd vs Ctrl)".
  - Phase 1 spec row C14: Static, one tag `line-kbd` at `./kbd`, no role placement, not form-associated,
    `agentExposed: true`, htmx `n/a` expected; the component spec settles OS-aware rendering.
  - Miguel's decisions, 2026-11-13, each the recommended option of `0015-kbd.md`:
    F1 (a) `navigator.userAgentData.platform`, then `navigator.platform`, Apple on
    `/^(Mac|iPhone|iPad|iPod)/i`, `other` without `navigator`, and a `platform` attribute `auto | apple | other`;
    F2 (c) a `keys` attribute with the default slot as fallback; F3 (a) Apple glyphs in Apple's modifier order with
    no separator, words joined by `+` elsewhere in the author's order, and PRD §4.1 "(Cmd vs Ctrl)" read as the
    Command-versus-Control distinction, so no PRD revision; F4 (a) `aria-hidden` glyphs beside visually hidden
    words in an `inline-flex` root; F5 (d) English defaults, the app-wide `LineKbd.keyLabels` and the per-host
    `key-labels` attribute; F6 (a) space-separated sequence steps with a hidden " then "; F7 (a) documentation only
    for `aria-keyshortcuts` on the owning control; F8 (a) parts `root`, `item` and `separator`. Orchestrator
    defaults D1–D22 stand as drafted.
  - Miguel, 2026-11-13, after docs review gate round 1:
    - Phase 1 spec AM-098, trigger `decision`, adds Kbd (`0015-kbd.md` D10) to the §6.G.4 Accessibility exception
      list, to SD47 and to the §6.G.3 acceptance. It also adds Alert, which ships `hostNaming: never`
      (`packages/line-genui/src/catalog/descriptors/alert.ts:36`; `0006-alert.md` D7, Miguel 2026-11-09) but was
      never listed, as a factual realignment in the same row.
    - Kbd sits in Button's default slot in the examples, Connections and Browser tier, not in `suffix`, which
      `0002-button.md:129` gives to a trailing icon. `<line-icon-button>` leaves the Connections row.
      `0002-button.md` and `button.ts` stay unchanged.
