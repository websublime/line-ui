## Understanding
- Outcome: `@websublime/line-components/avatar-group` registers `<line-avatar-group>`, a Custom-machine component
  that stacks slotted avatars, hides those past `max` behind a "+N" inner native `<button>`, and shows them in a
  native `popover` panel. It is exposed to agents through the `line` catalog.
- Stated:
  - ARCH §13.2 (`docs/ARCHITECTURE.md:606`): Custom machine, states `collapsed ↔ expanded ↔ overflow_open`, hover
    expands, a click on overflow opens a popover, props `max`, `size`, `spacing`.
  - Phase 1 spec row C11: avatars by slot, no import of Avatar (SD4); "+N" on an inner native `<button>` (SD31);
    resets `common` + `button`; `agentExposed: true`; htmx `n/a`.
  - Miguel's fork answers, 2026-11-11, each the recommended option of `0010-avatar-group.md`:
    F1 (c) native `popover` attribute, with the machine following its toggle events; F2 (a) mouse or pen hover
    plus focus inside the group expands, Esc collapses, touch never expands; F3 (a) the avatars past `max` move
    into a panel slot by manual slot assignment; F4 (a) manual slot assignment hides avatars past `max`; F5 (a)
    every element child counts; F6 (a) `group` role on the host through `ElementInternals`; F7 (a)
    `overflow-label` template with `{count}`, blank falls back to the visible "+N"; F8 (a) numbered step enums

    name; F11 (a) htmx `n/a`. Orchestrator defaults D1–D19 stand.

  recorded in `0010-avatar-group.md` Probes):

## Spec drift found
1. (decision, Miguel 2026-11-11: F7 (a)) Phase 1 spec §10 SD31 (`:2378`) has the "+N" control copy the host
   `aria-label`. The host label names the group (F6 (a)), and P3 shows such a name fails label-in-name against
   "+N". A Phase 1 spec AM with trigger `decision` keeps the inner native button and names the "+N" control
   from `overflow-label`.
2. (resolved by F4 (a), no AM) `0009-avatar.md:473` (G5) lets the group write `hidden`, while `:239` says it never
   writes attributes on slotted avatars. Manual slot assignment writes nothing.
3. (decision, Miguel 2026-11-11: strict chain, no AM) `docs/ARCHITECTURE.md:606` draws the states as a chain. The
   draft read it as a state set, so that a touch tap opened the panel straight from `collapsed`. Miguel chose the
   literal chain: the machine passes through `expanded` in the same event, in both directions. ARCH is unchanged.
4. (row) `docs/COMPETITIVE-COMPONENT-ANALYSIS.md` has no AvatarGroup row; C11 adds it under the §6.C.6
   obligation.
5. (factual, `0009` AM-004) `0009-avatar.md:476` (G8) says C11 tracks avatars "through `slotchange` only". Probe
   P2 of 0010 shows manual slot assignment fires no `slotchange` when a child is added, so C11 uses a
   `MutationObserver`.
6. (decision, Miguel 2026-11-11: add a `root` part) ARCH §14.9 (`docs/ARCHITECTURE.md:1250`) draws the default
   focus ring on `::part(root)`. The draft had no `root` part. A `root` wrapper around the "+N" button now carries
   the ring, so ARCH holds literally.
