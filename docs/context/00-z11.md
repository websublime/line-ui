## Decisions (Miguel, 2026-10-07)
1. **Status.** The agent contract and the catalog are firm; the A2UI renderer ships from the start in preview
   until A2UI v1.0 is final. Rejected: everything stable now; exploratory like HTMX.
2. **Timing.** The foundation is the first stream of Phase 1, validated with the first real components; every
   later component ships its descriptor in the same PR. Only the agent contract enters Phase 00, through the
   G4 template. Rejected: a new Phase 00 stream; shipping after Phase 2.
3. **Protocol.** A2UI first, on top of protocol-neutral Zod descriptors; frontend-tool JSON Schema comes from
   the same descriptors. Rejected: neutral descriptors only; json-render.
4. **Descriptor home.** `line-genui/src/catalog/`, with a CEM drift test and a coverage test (every component
   in the CEM has a descriptor). `line-components` gains no Zod or A2UI dependency. Rejected: colocated
   `*.agent.ts` beside each component.
5. **Catalogs.** Ship both the `line` catalog and the A2UI `basic` catalog built on line components. Rejected:
   `line` only.
6. **Name.** `@websublime/line-genui`. Rejected: `line-agent`, `line-a2ui`.
