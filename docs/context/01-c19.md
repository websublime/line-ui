## Understanding
- Outcome: `@websublime/line-components/aspect-ratio` registers `<line-aspect-ratio>`, a Static layout container
  that holds its content at a fixed width-to-height ratio, with `agentExposed: true` and an `AspectRatio`
  descriptor in the `line` catalog.
- Stated:
  - PRD §4.1 (`docs/PRD.md:266`): Static, "Maintains fixed width-to-height ratio for responsive media".
  - Phase 1 spec row C19: Static, tag `line-aspect-ratio` at `./aspect-ratio`, role settled by the component spec
    from R8 §2.2, not form-associated, `agentExposed: true`, htmx `n/a` expected.
  - R8 (`docs/research/01-research-accessibility.md:83`): no role, no name, no keyboard.
  - Tokens `--line-aspect-square|landscape|portrait|widescreen|ultrawide|golden`
    (`packages/line-tokens/src/aspects.css`).
  - Miguel's decisions, 2026-11-17, each the recommended option of `0021-aspect-ratio.md`:
    - F1 (a): `ratio` takes the six token names only; any other ratio goes through `--line-aspect-ratio-ratio` in
      consumer CSS.
    - F2 (a): the host is a one-cell grid with `aspect-ratio`; children share the cell, stretch, and are clamped
      by `max-*: 100%`.
    - F3 (a): the ratio holds and larger content overflows visibly; no clipping.
    - F4 (a): `object-fit: cover` on slotted `img` and `video`; consumer CSS on the child overrides it.
    - F5 (a): with no `ratio`, the box draws `square`.
    - F6 (b): literal fallbacks equal to the token values, so the box holds its ratio without `line-tokens`.
    - F7 (a): `ratio` and a single `child` (`ComponentId`) reach agents, in the `line` catalog only.
    - F8 (a): `hostNaming: never`; the AspectRatio tool carries no accessibility parameters (Phase 1 spec AM-103).
  - Miguel, 2026-11-17: the defaults D1–D22 stand as drafted.
- Observed (spec-draft probes P1–P12, Playwright on chromium, firefox and webkit, happy-dom, htmx 2.0.11 and 4.0.0,
  axe 4.14.0; recorded in `0021-aspect-ratio.md` Probes):
  - CSS cannot read a ratio from an attribute in any engine; a raw ratio written through a `<style>` binding
    injects CSS (P3).
  - Only the one-cell grid fills the box with an image, a bordered iframe and a video at the set ratio (P2).
  - Clipping hides the outside focus ring of a control that fills the box in all three engines (P5).
  - Chromium grows the box to its content in a flex column unless `min-block-size: 0` (P4, D9).
  - The A2UI basic catalogs carry no ratio concept, and the `line` catalog has no media type (P10).
- Assumed: none beyond defaults D1–D22.
