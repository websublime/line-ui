## Understanding
- Outcome: `@websublime/line-components/portal` registers `<line-portal>`, a Static component that shows its
  slotted content above the page in the browser top layer (`popover="manual"`), outside the clipping, transforms
  and stacking of its ancestors, while the content keeps its DOM position. It carries `agentExposed: false`.
- Stated:
  - PRD §4.1 (`docs/PRD.md:257`): Static, "Renders child content outside its DOM parent".
  - Phase 1 spec row C13: Static, no role placement, not form-associated, `agentExposed: false`, htmx `n/a`
    expected; the component spec settles focus and reading order after the move (R8 §2.2).
  - Miguel's decisions, 2026-11-12, each the recommended option of `0013-portal.md`:
    F1 (c) top layer through `popover="manual"`, no node moves; F2 (a) no target; F3 (a) native inheritance of
    theme, `dir`, `lang` and custom properties; F4 (b) a reflected boolean `disabled` renders the content in
    place; F5 (a) events bubble through the host natively, documented; F6 (a) focus and reading order follow DOM
    order; F7 (b) a public `bringToFront()` method re-shows the box above a modal opened later; F8 (a) htmx row
    `n/a` confirmed; F9 (b) new `agentExposed: false` reason: the content paints above the whole page, outside
    the surface, so an untrusted agent could cover the host's own UI. Orchestrator defaults D1–D17 stand.
  - Miguel, 2026-11-12: PRD §4.1 Portal row is revised to describe the top layer, with a PRD revision-log entry.
- Observed (spec-draft probes P1–P13, Playwright 1.64 on chromium, firefox and webkit, htmx 2.0.11 and 4.0.0,
  happy-dom 20.14.6; recorded in `0013-portal.md` Probes):
  - The top layer escapes clipping, transforms and stacking and keeps inherited values, event bubbling, form
    ownership, DOM focus and reading order, and the htmx paths (P1–P4, P9).
  - Every move option lost those, became inert inside a modal `<dialog>` (P8) and left the surface's
    `aria-busy`, live region and focus rule; the surface reconciler still owns a moved node and pulls it back on
    its parent's next update, so "escapes the `instanceId` reconciliation" is false (P10).
  - A box shown before `showModal()` sits under the dialog backdrop until re-shown (P8).
  - The top-layer box paints over page UI and takes its clicks (P1, P9).
