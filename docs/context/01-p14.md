### Live-call script (read from the file, not committed)
- The script imports `descriptors` and `frontendTools` from the built `packages/line-genui/dist/catalog`.
- For each provider with an API key in the environment, it emits that provider's tools with `frontendTools` and
  makes one forced call per tool. It skips a provider without a key.
- Anthropic calls go to `/v1/messages` with model `claude-sonnet-4-5`, the header
  `anthropic-beta: structured-outputs-2025-11-13`, `strict: true` on the tool and `tool_choice` set to that tool.
- It checks the returned arguments against the tool schema for unknown keys, types, enums, nullability and
  required keys.
- It writes a JSON log to `/tmp` and prints a Markdown summary for the #313 comment.
- The log `/tmp/line-live-providers-2026-11-18T14-44-00-290Z.json` holds 17 results, all from `anthropic`,
  all `ok`, all status 200.
- Two earlier attempts, started 14:39:58Z and 14:42:37Z, returned 17 of 17 HTTP 400 "credit balance too low"
  before the passing run.
