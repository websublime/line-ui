## Spec drift found
1. (decision, Miguel 2026-11-03: accept) Spec §4.1 `:218` says `./catalog` imports no module that touches the
   DOM at load. The common types it must reuse (ARCH §17.3) are reachable only through `@a2ui/web_core/v0_9`,
   which loads Lit unbundled. G4's `./a2ui` (`:211`, "never imports `lit`") meets the same barrel for
   `NodeResolver`.
2. (factual) §6.G.1 `:1320` requires every property description to go through the `REF:` helper. R3 §6 Q6(b)
   scopes it to common-type props, and upstream describes enums plainly.
3. (factual, wording) `childList()` drops the marker through a plain `.describe()` (`helpers.js:59-64`), which the
   `:1320` sentence about a literal `${description}` does not cover.
4. (decision, orchestrator default) Button `0002-button.md:269` names `aria-label` as the name source; under the
   default it becomes `accessibility.label`. Separator `0011-separator.md:278` is settled the same way.
5. (decision, Miguel 2026-11-03: iconMap) `0014-icon.md:320-339`: the `line` catalog names an icon through the
   surface `iconMap`; the prop schema drops `library` and `weight`.
