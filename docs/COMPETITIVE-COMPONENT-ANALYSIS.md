# line://ui — Competitive Component Analysis

This file compares line://ui with seven libraries, one component at a time. PRD [§1.3](./PRD.md#13-competitive-analysis) compares the libraries as a whole. Each Phase 1+ component spec records here what the other libraries ship for the same component, so the spec starts from known gaps. The competitor set comes from spec `docs/specs/00-spec-design-system.md` §6.G.4 (AM-048).

## How to fill

- A component spec appends its row to the table of its PRD §4 family, in the same PR as the spec.
- A cell holds the element or component name in that library, or `—` when the library ships no such primitive as of the row's check date.
- A footnote under the family table, keyed to the row, lists the source of every cell and the date they were checked.
- When an upstream library adds, renames or removes the primitive, update the cell, its source and the check date.

Spectrum's `<sp-action-button>` takes the icon in its `icon` slot and the name through `label`, flips `selected` under `toggles` and fires `change`, and `hold-affordance` adds `longpress`; `<sp-close-button>` and `<sp-clear-button>` draw a fixed cross glyph. `<line-icon-button>` is its own element: it renders a native `<button type="button">` in its shadow root, is not form-associated, takes the icon through its default slot (part `icon`), copies the host `aria-label` and `aria-description` to the inner button, and takes `variant` (`default`, `primary`, `borderless`), `disabled`, `loading` (slot and part `loading`) and `pressed` (`aria-pressed`, fires `line-change`). It is square through `--line-icon-button-size`, shares Button's press machine without importing Button, and a nameless IconButton node on the A2UI surface renders a placeholder. |
| Separator[^4.1-separator] | `<line-separator>` (`@websublime/line-components/separator`, spec `0011-separator.md`) | `<wa-divider>` | `<sp-divider>` | — | `<fluent-divider>` | `Separator` | `Separator` | — | Lion and Ark UI ship no separator. Radix and Bits take `orientation` and `decorative`, as `<line-separator>` does; Web Awesome takes `orientation` and a label, Spectrum a `vertical` boolean and `size`, Fluent `orientation`, `role`, `appearance`, `inset` and `align-content`. `<line-separator>` is the host itself as the line, with the `separator` role and its orientation as `ElementInternals` defaults, so author `role` and `aria-*` attributes win; it draws a border side, which stays visible in forced-colors mode, and has no label slot. |
| Stack[^4.1-stack] | `<line-stack>` (`@websublime/line-components/stack`, spec `0018-stack.md`) | — | — | — | — | — | — | — | None of the seven ships a stack element or component. Web Awesome ships `wa-stack`, `wa-cluster`, `wa-flank` and `wa-split` as CSS utility classes in `dist/styles/utilities/layout.css`, with no attributes and no agent contract. `<line-stack>` is the host itself as the flex container with a bare slot, so an author `role="list"` reaches its `role="listitem"` children; `orientation`, `justify` and `align` mirror the A2UI basic v0.9 `Row`, `Column` and `List` values, and `gap` is a closed `0`–`5` scale over `--line-layout-gap-*`. |
